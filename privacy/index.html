GreenPlayer 隐私政策

生效及更新日期：2026 年 8 月 22 日

简要说明

GreenPlayer 没有开发者账号系统、广告、分析 SDK 或业务后台。开发者不会接收您的媒体、播放记录、服务器地址或凭据。

1. 本机数据

您选择的文件和文件夹、媒体资料缓存、播放位置、应用设置、服务器地址及用户名在设备上处理。密码和访问凭据存入 Apple 系统钥匙串；海报和元数据缓存位于系统缓存目录。

GreenPlayer 不会访问您未通过系统文件选择器授权的文件，也不会把这些数据发送给 GreenPlayer 开发者。

2. 您主动连接的服务

连接 Jellyfin、Emby、SMB、WebDAV、FTP 或 DLNA 设备时，应用会按照您的操作直接与对应服务器或局域网设备通信。登录信息、媒体请求、播放进度和设备会话标识可能由该服务器处理。

这些服务由您或第三方运营，其数据处理受服务器所有者及相应服务的隐私政策约束。GreenPlayer 开发者不代理这些通信，也无法读取您自有服务器中的数据。

3. iCloud 配置同步

iCloud 配置同步默认关闭。您主动开启后，媒体服务器和网络文件来源配置、密码及应用设置会先以 AES-GCM 加密，再保存到您 Apple 账户的 iCloud KVS 私有空间；解密密钥通过 iCloud 钥匙串同步。

访问令牌、本地文件授权和播放记忆不会同步。GreenPlayer 开发者无法访问您的 iCloud 私有数据。

4. 保留、删除与控制

  • 您可以在应用中删除单个数据源并移除关联凭据。
  • 您可以清除媒体缓存或关闭播放历史显示。
  • 您可以在“设置”中删除 iCloud 配置并关闭同步。
  • 卸载应用会移除由系统管理的本机应用数据；若要删除 iCloud 配置，请先使用应用内删除功能。

GreenPlayer 没有开发者侧账号或服务器数据，因此不存在需要由开发者代为删除的 GreenPlayer 账号数据。其他仍开启同步的设备可能重新上传 iCloud 配置。

5. 系统权限

本地网络
连接您添加的 NAS、媒体服务器，以及发现和控制 DLNA 投屏设备。
Face ID、Touch ID 或设备密码
解锁您明确标记为需要保护的数据源。
文件访问
仅访问您通过系统文件选择器明确授权的文件或文件夹。

拒绝权限只会影响依赖该权限的功能。

6. 儿童与媒体内容

GreenPlayer 不面向儿童收集数据，也不提供或推荐任何媒体目录。应用播放的内容完全由用户选择；用户应确保自己有权访问和播放相关内容。

7. 本政策页面的托管

本页面由 GitHub Pages 托管，不包含 GreenPlayer 自有的分析代码、广告或 Cookie。GitHub 可能出于安全和服务运营目的处理访问日志等技术信息；相关规则请参阅 GitHub 隐私声明。这类网站托管数据不由 GreenPlayer 应用收集。

8. 联系与政策更新

如有隐私、数据控制或安全问题，请访问 GreenPlayer 技术支持页面。提交公开问题时，请勿附带密码、令牌、私有服务器地址或个人媒体内容。

应用的数据处理方式发生实质变化时，本政策会相应更新，并修改页面顶部的更新日期。
