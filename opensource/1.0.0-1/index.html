校验与使用

  1. 下载 ZIP 和同名 .sha256 文件。
  2. 在终端运行 shasum -a 256 GreenPlayer-OSS-1.0.0-1.zip。
  3. 比对输出与校验文件；解压后还可使用包内 SOURCE-SHA256SUMS.txt 逐项核验源码归档。
