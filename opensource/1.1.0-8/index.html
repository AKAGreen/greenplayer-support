许可与范围

GreenPlayer 的兼容播放通过 MPVKit 1.0.0 使用 mpv 0.41.0 和 FFmpeg 8.1.2。本构建的 FFmpeg 使用 LGPL-3.0-or-later（启用 version3，未启用 GPL/nonfree）；mpv 使用 LGPL-2.1-or-later，MPVKit 使用 LGPL-3.0。对应源码、构建脚本、修改记录和许可文本可从上方源码包下载。

各组件仍由原版权所有者按其许可证授权。本页面不对 GreenPlayer 应用代码授予开源许可。最终提交构建须与此页的版本、构建号及源码包依赖对应；材料公开不表示 App 已审核通过或已经上架。

校验

下载后运行 shasum -a 256 GreenPlayer-OSS-1.1.0-8.zip，并与同名 .sha256 文件比较。解压后还可用 SOURCE-SHA256SUMS.txt 逐项核验。
