# GreenPlayer Support

Public, static privacy policy and support pages for GreenPlayer.

- Privacy policy: <https://akagreen.github.io/greenplayer-support/privacy/>
- Support: <https://akagreen.github.io/greenplayer-support/support/>

The site contains no application source code, analytics, advertising, external
fonts, or JavaScript. It is published with GitHub Pages from the `main` branch.
